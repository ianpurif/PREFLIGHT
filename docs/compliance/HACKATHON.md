# Hackathon Integrity Checklist

This repository is submitted to the Classic / From Scratch track. The project-origin declaration and
repository chronology are recorded in
[`graph-start-fresh-eligibility-2026-09-11.md`](evidence/graph-start-fresh-eligibility-2026-09-11.md).

- Project-specific implementation begins during the hackathon.
- Public libraries/starter kits may be used and must remain transparent.
- Keep chronological version-control history; avoid a single final-day mega-commit.
- Distinguish reused starter material from newly written project work.
- AI tools may assist but human/team direction must be meaningful.
- Document where/how AI materially contributed.
- If using spec-driven workflows, keep prompts/plans/spec artifacts in the repository.
- Demo/submission must expose the actual new work, not imply pre-existing code was created during the event.

This boilerplate itself is AI-assisted and is recorded in `docs/ai/AI_USAGE.md`.
