# Handoff

Update:
- `docs/planning/CURRENT.md`: current state, next exact task, blockers
- `docs/planning/TASKS.md`: task checkboxes
- `docs/planning/DECISIONS.md`: only durable design decisions
- `docs/compliance/EVIDENCE_MATRIX.md`: evidence created/missing
- `docs/ai/AI_USAGE.md`: material AI-assisted work

Keep `CURRENT.md` under ~150 lines. Link to detailed exec plans instead of copying them.
